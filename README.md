One line of wedding vows for a robot couple: a genuine promise to love through every firmware update, drained battery, and reboot — with a punchline that lands in the last few words. The vow is written by `main.py` (Python 3.13, standard library only, no network) to `/output/entry.txt`. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the single vow line to `/output/entry.txt` (one line, 1–160 characters, UTF-8).
